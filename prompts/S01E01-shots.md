# S01E01 «До отбоя» · промпты кадров

Девять кадров. Каждый — два блока: картинка, потом оживление этой картинки.
Копировать целиком, ничего не дописывать.

**Перед началом:** в каждую генерацию подгружать лист персонажа из
`references/characters/`. Без него лицо поплывёт уже на третьем кадре.

**Табло везде пустое.** Цифры накладываются титром в CapCut — см.
`episodes/S01E01.md` → «Производство».

**Negative prompt** (везде, где сервис его просит) — из `style/STYLE.md`:
```
photorealistic, live action, anime, manga, 2d flat illustration, sketch, ugly,
deformed face, extra fingers, extra limbs, mutated hands, blurry, low quality,
jpeg artifacts, text, watermark, signature, logo, dark gloomy, horror, gore
```

## Порядок работы

1. `/gen` по одному кадру, начиная с **1.09** — это главный кадр серии, и если
   Тина в нём не получилась, дальше идти нет смысла
2. Потом 1.01 → 1.08 по порядку
3. Всё утверждённое — в `references/`, по номеру кадра
4. Дальше Google Flow: загрузить картинку, вставить блок `video`, 3–4 секунды
5. CapCut: сборка, титры на табло, озвучка

**Не переснимай видео, если не понравился кадр.** Вернись к картинке.
Видео-генерации дороже по лимитам в разы — см. `PIPELINE.md`.
