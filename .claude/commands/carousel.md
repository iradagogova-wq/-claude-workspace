Делаем бесшовную карусель: **$ARGUMENTS**

Механика: одна широкая AI-сцена генерируется целиком, потом разрезается на
слайды. Стык между слайдами — это буквально один и тот же кадр, разрезанный
пополам, поэтому шов идеальный всегда, без исключений. Никаких сторонних
сервисов — файлы уже готового размера 1080×1350, оператору остаётся только
скачать и выложить каруселью.

**Если ключа нет** (`GEMINI_API_KEY` не задан) — скажи об этом первой строкой
и дай инструкцию из `TOOLS.md`, раздел «Ключ Gemini». Не притворяйся, что
сгенерировал.

## Порядок

1. Разбери тему оператора и сам сформулируй один английский промпт цельной
   сцены — без текста, без коллажа, один непрерывный кадр (скрипт сам
   дописывает эти правила композиции, повторять их в промпте не нужно).
   Промпт должен явно описывать, что происходит **по всей ширине** сцены
   (не один объект в центре кадра), иначе после разреза слайды будут
   выглядеть как две половины одного портрета, а не как поток.

   Хороший ориентир — примеры вирусного формата: один крупный
   объект/персонаж, действие или композиция которого тянется через весь
   кадр (океан и брызги, светящееся существо, разворачивающаяся ткань).

2. Запусти генерацию (по умолчанию 2 слайда — самый надёжный вариант,
   именно так сделаны все вирусные примеры формата):

   ```
   python3 scripts/gen_carousel.py "<промпт>" \
     --slides 2 --out references/carousels/<короткое-имя-темы>
   ```

   Три слайда — тот же принцип, чуть более узкий кадр по высоте:

   ```
   python3 scripts/gen_carousel.py "<промпт>" \
     --slides 3 --out references/carousels/<короткое-имя-темы>
   ```

3. Покажи результат оператору через SendUserFile — все слайды сразу, по
   порядку. Явно скажи, в каком порядке грузить в Instagram (1, 2, ...).

4. Если оператор хочет текстовый хук на первом слайде («КАК СДЕЛАТЬ...»,
   «→ листай» и т.п.) — не пытайся вписать текст в промпт генерации,
   AI-модели рисуют текст криво, особенно кириллицу. Предложи добавить
   надпись поверх готового слайда через Canva (уже подключён как коннектор) —
   это отдельный, необязательный шаг поверх готовой бесшовной картинки.

## Правила

- Не больше 2 карусели (4-6 картинок) за один заход — тот же дневной лимит
  Gemini, что и у `/gen`.
- При ошибке 429 — дневной лимит исчерпан, скажи честно, сброс в 03:00 МСК.
- Если модель отклонила промпт (пустой ответ / `promptFeedback`) — не
  выдумывай, скажи как есть и предложи переформулировать.
- Файлы карусели в git не попадают (см. `.gitignore`), живут только в
  сессии — оператор сохраняет понравившийся вариант себе на телефон.
