Генерируем: **$ARGUMENTS**

Картинки генерируются здесь, в чате, через `scripts/gen_image.py` (бесплатный Gemini API).
Оператору ничего открывать не нужно.

**Если ключа нет** (`GEMINI_API_KEY` не задан) — скажи об этом первой строкой и дай
инструкцию из `TOOLS.md`, раздел «Ключ Gemini». Не притворяйся, что сгенерировал.

## Порядок

1. Собери промпт ровно так же, как в `/shots` — STYLE BLOCK + Locked prompt block
   дословно + действие + план + свет.

2. Запусти генерацию:

   Лист персонажа (без референса, 3 варианта на выбор):
   ```
   python3 scripts/gen_image.py "<промпт>" --n 3 \
     --out references/characters/<имя>.png
   ```

   Кадр серии (обязательно с листом персонажа как референсом):
   ```
   python3 scripts/gen_image.py "<промпт>" \
     --ref references/characters/<имя>.png \
     --out references/<серия>/<номер>.png
   ```

3. Покажи результат оператору через SendUserFile, чтобы он увидел кадр в чате.

4. Отметь кадр сделанным в shot list файла серии.

## Правила

- Не больше 8 кадров за один заход — упрёшься в лимит запросов в минуту
- В кадры с персонажем **всегда** передавай `--ref` с листом персонажа.
  Без него лицо будет новым каждый раз — это главная ошибка
- Лист персонажа генерируй с `--n 3`, дай оператору выбрать
- При ошибке 429 — дневной лимит исчерпан, скажи честно, сброс в 03:00 МСК
- Файлы кадров в git не попадают (см. `.gitignore`), они живут только в сессии.
  Понравившийся кадр оператор сохраняет себе на телефон
