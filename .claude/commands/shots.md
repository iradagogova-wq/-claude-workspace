description: Выдать готовые промпты картинок для кадров
argument-hint: [диапазон кадров, например: 1-8]
---

Кадры: **$ARGUMENTS**

Прочитай активный файл серии из `episodes/`, `style/STYLE.md` и файлы всех
персонажей, занятых в этих кадрах.

Для каждого кадра выдай ОДИН блок, готовый к копипасту целиком:

```
SHOT <номер> · image
<STYLE BLOCK дословно из style/STYLE.md> + <LOCKED BLOCK персонажа дословно
из characters/> + <действие> + <локация> + <план> + <свет>
```

Жёсткие правила:
- Locked prompt block копируется **дословно**, символ в символ. Не перефразируй,
  не сокращай, не «улучшай». Это главный источник брака
- Порядок частей строго как в `style/STYLE.md`
- Одно ясное действие на кадр
- Максимум 10 кадров за раз — дальше упрёшься в дневной лимит

Под блоками одной строкой напомни: подгрузить лист персонажа из
`references/characters/` как reference image, сохранять результат как
`references/<серия>/<номер>.png`.

Если кадров запрошено больше 10 — выдай первые 10 и скажи, сколько осталось.
