Оживляем: **$ARGUMENTS**

Видео делается локально через `scripts/animate.py` — бесплатных видео-моделей
не существует, поэтому движение создаётся камерой и досочинением кадров.
Способы и их границы описаны в `METHODS.md`.

## Один раз за сессию

Контейнер эфемерный, ffmpeg надо ставить заново:
```
uv pip install --system imageio-ffmpeg
```

## Выбор способа

- **Кадр статичный, нужен живой план** → `ken`. Наезд для нарастания,
  отъезд для раскрытия, панорама для перехода
- **Персонаж должен что-то сделать** → сгенерируй `/gen` вторую позу
  с тем же `--ref`, затем `morph`
- **Сложное действие** → 6–10 поз через `/gen`, затем `seq`
- **Моргание, губы, покачивание** → SVG через Chromium, без лимитов

```
python3 scripts/animate.py ken references/S01E01/1.03.png --out clips/1.03.mp4 --sec 4 --move in
python3 scripts/animate.py morph references/S01E01/1.04a.png references/S01E01/1.04b.png --out clips/1.04.mp4
python3 scripts/animate.py join clips/1.01.mp4 clips/1.02.mp4 --out scene.mp4
```

## Правила

- Чередуй движения камеры между планами. Три наезда подряд — зритель укачивается
- Обе позы для `morph` генерируй с одним листом персонажа, иначе лицо сменится
- Готовый клип показывай оператору через SendUserFile
- Отмечай кадр сделанным в shot list серии
