argument-hint: [номер серии и идея, например: S01E02 герой теряет сумку]

Серия: **$ARGUMENTS**

Прочитай `episodes/SERIES.md`, `episodes/_TEMPLATE.md`, все файлы из `characters/`
и `style/STYLE.md`.

Создай файл серии по шаблону:

1. **Логлайн и три акта.** Худший момент героя — примерно на 2/3 хронометража
2. **Shot list** — таблица кадров по 5 секунд. Для каждого: план, что в кадре,
   одно движение камеры, чекбоксы статуса
3. **Реплики** с пометками интонации, на языке сериала

Правила раскадровки:
- Чередуй планы: общий → средний → крупный. Три одинаковых подряд — брак
- Сцены с двумя персонажами по возможности разбивай на восьмёрку (кадр на одного,
  кадр на другого) — бесплатные модели ломают лица в групповых планах
- Переиспользуй локации из библии сериала

После записи выведи: логлайн, количество кадров, сколько это дней по лимитам
(см. `TOOLS.md`), следующий шаг — `/shots 1-8`.
