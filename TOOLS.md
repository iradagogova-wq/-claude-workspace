# Бесплатные инструменты и их лимиты

Всё открывается в Safari на айфоне. Добавь на домашний экран через «Поделиться →
На экран Домой» — будет работать как приложение.

## Видео (главный расход лимитов)

| Сервис | Бесплатный лимит | Вотермарк | Для чего |
|---|---|---|---|
| **Google Flow** (flow.google) | ~50 кредитов/день ≈ 12 роликов | нет | Основной. Veo 3.1, есть звук, есть первый+последний кадр |
| **Seedance 2.0** | 100 кредитов/день, 1080p | **нет** | Второй основной, когда Flow кончился |
| **Hailuo AI** | дневные кредиты | есть | Оживление картинки, хорошая мимика |
| **PixVerse** | дневные кредиты | есть | Запасной |

Вход в Flow — обычным личным Google-аккаунтом.

## Картинки — генерируются прямо в чате ✅

Открывать ничего не нужно. Команда `/gen` вызывает `scripts/gen_image.py`,
который ходит в бесплатный Gemini API и присылает готовый кадр сюда.

| Что | Лимит бесплатного ключа |
|---|---|
| **Gemini API** (`gemini-2.5-flash-image`) | сотни картинок в день, 1024×1024 |

### Ключ Gemini — настроить один раз

1. На телефоне открой **aistudio.google.com** → **Get API key** → **Create API key**
2. Скопируй ключ (начинается на `AIza…`)
3. Пропиши его в настройках окружения Claude Code как переменную `GEMINI_API_KEY`

Лучше именно в настройки окружения, а не сообщением в чат: тогда ключ переживёт
перезапуск и не останется в переписке. Если пришлёшь в чат — тоже сработает,
но только до конца этой сессии.

| Сервис | Лимит | Для чего |
|---|---|---|
| **Canva** | бесплатный тариф | Титры, обложки, превью. Уже подключён к чату как коннектор |

## Бюджет одной серии (3 минуты ≈ 36 кадров)

| Этап | Где | Твоё участие |
|---|---|---|
| 36 кадров-картинок | здесь, командой `/gen` | посмотреть и сказать «переделай 4-й» |
| 36 видео по 5 сек | Google Flow, ~3 дня | загрузить кадр, вставить промпт |
| Озвучка + сборка | AI Studio / CapCut, 1 вечер | руками |

**Итого: 4–7 дней, 0 рублей.**

Тяжёлая часть — перебор кадров до попадания в стиль — теперь на мне.
Руками остаётся только видео: бесплатного API для него не существует ни у кого.
