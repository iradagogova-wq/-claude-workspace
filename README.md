# 🎬 Бесплатная мультстудия

Рабочее пространство для создания мультфильмов и сериалов в стиле Pixar/Disney.
Без единой платной подписки. Работает с айфона.

---

## Как это устроено

Генерация видео нейросетью стоит денег — но у всех крупных моделей есть **дневные
бесплатные лимиты**. Студия построена так, чтобы в них укладываться.

**Claude** — сценарист, режиссёр и художник-постановщик: пишет сценарий, держит
персонажей одинаковыми от кадра к кадру, выдаёт готовые промпты.
**Бесплатные сервисы на айфоне** — рендер-ферма: превращают промпты в картинки и видео.

Claude не генерирует видео. Он делает то, на чём обычно всё разваливается:
удерживает единый стиль и узнаваемые лица через сотни кадров.

## Начать за пять минут

1. Открой `TOOLS.md` — поставь **Google Flow**, **Google AI Studio** и **CapCut**.
   Через Safari → «Поделиться» → «На экран Домой».
2. Открой чат в этом репозитории и скажи: **«Хочу сериал про <идея>»**
3. Дальше веди по шагам `PIPELINE.md` — от библии сериала до собранной серии.

Можно кидать в чат референсы картинками — стиль, персонажей, свет.

---

## Команды студии

Набери `/` в чате — команды появятся списком, выбирать пальцем.

| Команда | Что делает |
|---|---|
| `/series <идея>` | Библия сериала: мир, тон, палитра, состав персонажей |
| `/hero <имя>` | Персонаж с Locked prompt block + промпт турнэраунда |
| `/episode <номер> <идея>` | Сценарий серии и раскадровка по кадрам |
| `/shots 1-8` | Готовые промпты картинок для кадров |
| `/gen 1-8` | **Сгенерировать кадры прямо в чате** |
| `/animate 1-8` | Промпты оживления утверждённых кадров |
| `/ref стиль` | Разобрать присланную картинку в промпт-блок |
| `/status` | Что снято, что осталось, сколько дней |

Обычный порядок: `/series` → `/hero` → `/gen` → `/episode` → `/gen` → `/animate` → сборка в CapCut.

## Три правила, на которых всё держится

1. **Лист персонажа — до первой сцены.** Один турнэраунд, который подгружается
   в каждую генерацию. Без него персонаж будет разным в каждом кадре.
2. **Locked prompt block не меняется никогда.** Дословная копия во всех кадрах.
3. **Сначала картинка, потом оживление.** Text-to-video напрямую ломает лицо.

## Честно о качестве

Бесплатные модели дают крепкий, приятный результат — но не студийный Pixar.
Слабые места: руки, толпа, несколько персонажей в одном кадре, длинные диалоги
с попаданием в губы. Студия построена так, чтобы обходить их: короткие кадры,
восьмёрка вместо групповых планов, переиспользование локаций.

Серия на 3 минуты — это 4–7 дней по паре часов и 0 рублей.
