# Референсы

Сюда складывается всё визуальное. Это память студии между чатами.

```
references/
├── characters/   ← листы персонажей (турнэраунды). Главные файлы студии
├── style/        ← кадры-эталоны: «вот такой свет и цвет мне нужен»
└── S01E01/       ← готовые кадры серии, по номеру: 1.01.png, 1.02.png ...
```

## Как присылать референсы

Просто кинь картинку в чат и скажи, что это:

- «вот такой стиль хочу» → я разберу его на промпт-блок и запишу в `style/STYLE.md`
- «вот такая героиня» → я соберу по ней Locked prompt block в `characters/`
- «вот такой свет» → добавлю формулу света в стилевую библию

Я не могу сохранить присланную картинку в репозиторий сам — но могу разобрать её
в текст, а текст переживёт любой чат. Именно текст, а не картинка, воспроизводит стиль.
