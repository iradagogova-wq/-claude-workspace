# Слайды карусели EL VITA

Слайды 5 и 6 в стиле слайдов 1–4: тёмный сине-сливовый кадр, тёплый свет лампы справа,
белый жирный заголовок с розовыми акцентами, круглые бейджи-иконки, пунктирные разделители.

| Файл | Что это |
|---|---|
| `out/slide5.png` | Слайд 5, 1080×1440 — готов к публикации |
| `out/slide6.png` | Слайд 6, 1080×1440 — готов к публикации |
| `out/slide5@2x.png`, `out/slide6@2x.png` | те же слайды 2160×2880 — для печати и ретины |

## Как поменять текст

Текст лежит прямо в `src/slide5.html` и `src/slide6.html` обычными строками.
Розовый акцент — это `<span class="pink">…</span>`. Переносы строк ставятся вручную
через `<br>`, чтобы строки рвались по смыслу, а не по ширине.

## Как пересобрать картинки

```bash
cd src
npm i playwright            # если ещё не стоит
node render.mjs             # соберёт оба слайда
node render.mjs slide5      # только пятый
```

Рендерит headless Chromium в PNG 1080×1440 и 2160×2880. Вся графика — код:
баночки, полка, таблетки, боке и зерно рисуются в `art.js`, поэтому цвет,
размер и подписи на этикетках меняются одной строкой, без графического редактора.

Генератор случайных чисел в `art.js` детерминированный (`SEED`) — один и тот же
исходник всегда даёт один и тот же кадр. Поменяй `SEED`, если нужна другая
раскладка боке и книг на фоне.

## Шрифт

Montserrat (SIL Open Font License 1.1), кириллица + латиница, веса 400–800.
Файлы лежат в `src/fonts/`, чтобы рендер не зависел от интернета.
