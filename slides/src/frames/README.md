# Кадры с персонажами

Сюда кладутся сгенерированные кадры с мамой и дочкой — те самые, что на слайдах 1–4.
Промпты: `prompts/carousel-elvita-5-6.md`. Внешность — `characters/mama.md`, `characters/dochka.md`.

| Файл | Куда попадёт |
|---|---|
| `slide5.png` | фон слайда 5 |
| `slide6.png` | фон слайда 6 |

Размер кадра — вертикаль 3:4, минимум 1080×1440. Персонажи в правой половине кадра,
левые 45% — пустая тёмная стена: туда ложится текст.

Как только файл появился, `node render.mjs` сам переключается в режим кадра:
рисованная полка и банки прячутся, включается тёмная градиентная подложка слева.
Пока файла нет — собирается рисованная версия, ничего не ломается.
